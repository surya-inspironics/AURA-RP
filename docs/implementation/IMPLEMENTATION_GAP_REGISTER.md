## First-batch proposal

Before any implementation, approve the source requirement baseline and policy owners. The smallest safe coding batch after approval is a security boundary slice: strict authentication and tenant-membership enforcement on the existing API, with tests covering every router and a disposable test database. It does not redesign the UI, implement gold-loan financial rules, or enable external money movement.
